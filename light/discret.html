Mode discret : Light déguisée en calculatrice

Si quelqu'un regarde votre téléphone, il ne voit qu'une calculatrice qui fonctionne vraiment. Light ne s'ouvre qu'avec votre code secret.

  1. Ouvrez la calculatrice. Elle calcule normalement.
  2. Tapez votre code secret, puis « = ». Light s'ouvre.
  3. « Quitter » ou la touche Échap vous ramènent à la calculatrice. Light se referme aussi seule si vous changez d'application.
  4. Si on vous force à ouvrir, tapez le code leurre puis « = » : un simple historique de calculs s'affiche.

Ouvrir la calculatrice

Installer la calculatrice sur l'écran d'accueil

L'icône et le nom affichés seront ceux d'une calculatrice.

  • Android (Chrome) : ouvrez la calculatrice, menu ⋮, puis « Ajouter à l'écran d'accueil » ou « Installer l'application ».
  • iPhone (Safari) : ouvrez la calculatrice, bouton Partager, puis « Sur l'écran d'accueil ».

Réglages

Codes de démonstration actifs. Le code secret 1234 et le code leurre 0000 sont publics : un vrai service vous demanderait de choisir vos propres codes dès la première ouverture.

Chiffres uniquement, de 4 à 8 chiffres ; 6 ou plus est conseillé. Les deux codes doivent être différents. Ils ne sont jamais enregistrés en clair : seule une empreinte est gardée sur ce téléphone.

Les limites du mode discret

  • Si Light est ouverte dans le navigateur (et non installée), son adresse peut rester dans l'historique : préférez l'application installée ou la navigation privée.
  • Un code de 4 chiffres se devine facilement : choisissez-en un plus long, que la personne qui vous fait du mal ne peut pas deviner (pas votre date de naissance).
  • Le camouflage ne protège pas d'un logiciel espion installé sur le téléphone.
  • Si vous oubliez votre code, effacez les réglages ci-dessous : les codes de démonstration reviennent.
