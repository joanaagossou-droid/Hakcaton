Confidentialité, en clair

Modèle de démonstration en langage simple. Un vrai service devra le faire valider par un juriste.

1. Ce que nous collectons

Dans ce prototype : le formulaire « Écrire » n'envoie et n'enregistre rien. Les fonctions de « Mon espace » (message vocal, preuves, alerte discrète) et le calcul secret du mode discret sont enregistrés uniquement sur ce téléphone, dans le stockage du navigateur ; rien n'est envoyé à un serveur. Le calcul secret est gardé sous forme d'empreinte, les preuves sont chiffrées avec lui. Dans un vrai service, nous ne demanderions que votre message ; votre nom et votre numéro resteraient facultatifs.

2. Qui peut lire

Dans un vrai service : uniquement l'équipe d'écoute formée, et personne d'autre. Les personnes autorisées seraient désignées par leur fonction.

3. Combien de temps nous gardons les messages

Dans un vrai service : 30 jours au plus, puis suppression automatique. Ici : tout reste sur ce téléphone jusqu'à ce que vous l'effaciez (« Mode discret » → « Tout effacer »), ou jusqu'au traitement par la console de démonstration, qui supprime l'audio.

4. Où sont les données

Ce site ne possède pas de base de données sur un serveur : la console agent de démonstration lit seulement les messages enregistrés dans le même navigateur. L'hébergeur garde des journaux techniques (adresse IP, date, page demandée) pendant une durée limitée, pour faire fonctionner le service. Nous ne les utilisons pas pour suivre les visiteurs.

5. Supprimer vos données

Dans un vrai service : vous pourriez demander la suppression de votre message avec votre code de suivi, sans donner votre nom.

6. Ce que nous ne faisons jamais

Pas de traceur, pas de publicité, pas de revente, pas de notification, pas de SMS, pas de courriel automatique, pas d'intelligence artificielle extérieure (l'assistante fonctionne avec des règles, sur ce téléphone). La transcription automatique d'un message vocal en français est désactivée par défaut : si vous l'activez vous-même, le son passe par le service de reconnaissance vocale du navigateur, un service extérieur. Sans elle, une personne écoute votre message.

7. Les limites de la confidentialité

La confidentialité a des limites. Un vrai service doit vous le dire avant que vous écriviez :

  • si vous avez moins de 18 ans et que vous êtes en danger, certains professionnels doivent prévenir les services de protection de l'enfance ;
  • si une vie est en danger immédiat (la vôtre ou celle d'une autre personne) ;
  • si la loi impose un signalement.

Dans ces cas, le service vous prévient avant, sauf en cas de danger immédiat. Les obligations exactes au Bénin doivent être vérifiées par un juriste avant tout usage réel.
